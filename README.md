# Zenko
A vibe-coded prototype for my own personally Japanese language study. This was worked on long before I learned github or understood the importance of it in project management. This project was imported from google drive folder that had archives from my old desktop. 

## Version history

The recovered `v0.2.0` and `v0.2.1` project snapshots contain identical source files. The project is kept at the repository root, and the `v0.2.1` history entry records the later snapshot without claiming any source changes that were not present in the archives.
